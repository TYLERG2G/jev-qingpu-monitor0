## 3. 問題意識（【建議預設】的推定，待使用者確認）
- 同一間住宅常常被多位仲介、在多個平台重複刊登；資訊不一致，而且多半不揭露完整門牌。
- 有些刊登掛上社區名稱，實際卻是鄰近建案（誤植或蹭名）。
- 價格變動與下架很難即時察覺；也很容易把舊刊登誤當成新上架。
