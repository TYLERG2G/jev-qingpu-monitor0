## 2. 逐則判定
「規則判定」依現行 06 規則與目前名冊狀態（mapping 是 TRANSCRIBED_UNVERIFIED、沒有 VERIFIED 的推導規則與坪型）推出；「人工縮小」是分析者用推論性坪型做的參考，**不是**系統結果，也不是答案。

### L1 信義 2068MR
- 社區歸屬：M2（信義社區頁列為本社區）+0.5、M3（名稱）+0.2、M4（高鐵南路一段）+0.2 = 0.9 → `MEMBER`。
- 棟別：「該層戶數 5」——591 示意圖中只有 D 棟（D1、D2、D3、D5、D6）是 5 戶；A、B、C 棟都是 4 戶 → 推論為 **D 棟**（推論：假設信義的「該層戶數」指同一梯廳或棟別）。
- 樓層：12F（來源事實，`floor_exact`）。
- 戶別：權狀扣除車位約 36.11 坪。591 成交參考值：D2（103號）36.1、D5（107號）35.6／36.1、D1 32.0、D3 33.6、D6 32.1 → 人工縮小到 **D2、D5**。
- **規則判定**：G2 → 17 個 12 樓候選；坪型沒有 VERIFIED，所以 X6 只能軟反駁；「該層戶數」目前沒有對應規則 → `MULTIPLE_CANDIDATES`（排序偏向 D2、D5）。
- **人工縮小結果**：候選 = 高鐵南路一段 103號12樓（D2）、107號12樓（D5）；排除 D1、D3、D6（坪數差 2.5–4 坪）與 A–C 棟（每層戶數不符）。**沒有確認完整門牌**。
- **補充（方位推論）**：「落地窗東北」→ 推論為 D 棟右欄（D2、D3、D5），與坪數篩選一致，但**無法再區分 D2、D5**（兩戶都在右欄）。需要照片判斷前段或後段（例如窗景、是否靠 C 棟）。
