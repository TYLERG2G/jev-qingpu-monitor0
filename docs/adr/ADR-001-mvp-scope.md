# ADR-001 MVP 範圍

- 狀態：**提議中**（【建議預設】，尚未經使用者確認；Q-020、Q-021）
- 日期：2026-10-17 提出；2026-10-18 修訂（更正：第一版誤標為「已接受」）

## 背景
需求涵蓋房源監控、同屋辨識與完整門牌推斷【已確認】。試點社區已確認是聯上世界【已確認】。交易類型、使用者數量、是否商業使用都還沒確認。

## 提議
| 項目 | 提議 | 狀態 |
|------|------|------|
| 社區 | 只有聯上世界 | 【已確認】試點社區；只做一個社區是【建議預設】 |
| 交易類型 | 中古屋買賣（`deal_type = SALE`） | 【建議預設】Q-020 |
| 使用者 | 單一使用者、個人非商業，用 API key 驗證 | 【建議預設】Q-021 |

## 後果
- 好處：規則與名冊可以針對單一社區調校。
- 壞處：如果改成租賃或多使用者，要補價格事件與權限。
- 緩解：資料模型保留 `community_id`、`deal_type`。

## 改成「已接受」的條件
使用者明確回覆 Q-020 與 Q-021，並寫入 decision-log。
