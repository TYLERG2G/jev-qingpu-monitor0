# ADR-003 資料來源策略

- 狀態：**提議中**（【建議預設】；依 Q-003、Q-024 的查證結果更新）
- 日期：2026-10-17；2026-10-18 修訂

## 背景
- 優先來源是 591 與樂居【已確認】；其他來源是次要候選。
- 各來源的條款與授權方式都【待查證】。
- 第一版有兩個錯誤，已經更正：
  1. 第一版曾把人工匯入說成「零合規風險」。
  2. 把所有需要驗證的來源一律排除。

## 提議
1. **人工記錄是一等公民**：走完整的證據、評估與事件流程；每筆都記錄原始出處，並沿用該出處的權利設定。
2. **權利分四項記錄**：取得、保存、圖片利用、再發布（03 §2）。UNKNOWN 時採取保守處理。
3. **依授權使用介面是允許的**：官方 API、條款允許的會員功能（`AUTHORIZED_API`、`AUTHORIZED_ACCOUNT`）。需要驗證**不等於**禁止。
4. **繞過存取限制一律禁止**：破解 CAPTCHA、偽造身分、輪換 IP、違反條款的自動化登入。
5. 自動擷取以來源為單位，預設關閉；要符合 03 §5 的條件才能啟用。
6. 名冊資料準備依 source-log §4 的順序；不預設使用者提供完整 CSV。

## 後果
- 好處：合規風險可控；沒有自動來源時，MVP 仍然可以運作。
- 壞處：人工記錄有操作成本；即時性取決於使用者。
- 後續：M0 查證後，每個來源補一份紀錄（ADR-003a、ADR-003b…）。
