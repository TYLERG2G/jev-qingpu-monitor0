# ADR-002 儲存：SQLite（MVP），保留遷移到 PostgreSQL 的路徑

- 狀態：**提議中**（【建議預設】，依 Q-006 決議）
- 日期：2026-10-17；2026-10-18 修訂

## 背景
【建議預設】單一使用者、單機運作。資料量主要來自快照、證據與評估歷史（評估與證據保留歷史，不覆寫），規模會比第一版預估大，但單一社區仍然很小。

## 提議
- SQLite（WAL），透過 SQLAlchemy 2 + Alembic 存取；避免使用 SQLite 特有語法。
- JSON 欄位存成 TEXT，在應用層驗證。
- 樂觀鎖使用 `version` 欄位；冪等使用 `idempotency_record` 表。

## 替代方案
| 方案 | 不選的原因 |
|------|------------|
| PostgreSQL | 單機單人使用時，維運成本不划算；多使用者或雲端時再遷移 |
| 檔案（CSV、JSON） | 無法保證唯一約束、交易與冪等 |

## 後果
備份就是複製一個檔案。如果 Q-006 或 Q-021 的決議改變，就重新評估。
