# ADR-005 證據與可信度模型

- 狀態：**提議中**（原則是使用者需求【已確認】D-009；模型細節是【建議預設】）
- 日期：2026-10-18

## 背景
第一版只用 `score` 與 `reasons_json`，無法表達：證據出處與版本、支持或反駁哪個候選的哪個欄位、同源抄錄造成的重複加分、證據過期與撤回、人工確認的依據。分數也被暗示成機率。

## 決策（提議）
1. **證據是一等實體**（05 §3、§5.1）：分成 `SOURCE_FACT`、`INFERENCE`、`HUMAN_ASSERTION`；記錄出處（快照、文件、覆核）、觀測時間、定位、摘錄與雜湊；推論必須記錄 `derived_from`。
2. **證據關聯**：`evidence_link` 標明支持或反駁的標的（歸屬、候選、配對、名冊 mapping）與欄位。
3. **獨立性**：每條規則在一次評估中只計一次；需要「獨立來源」的條件以獨立根來源群數計算（v0.2 的 `dependency_group` 做法已由下方 v0.3 修訂取代）。
4. **生命週期**：ACTIVE、STALE、SUPERSEDED、RETRACTED；狀態變更會觸發重新評估。
5. **評估有版本**：記錄規則版本、名冊版本、使用的證據集合；新的評估取代舊的，但不刪除舊的。
6. **人工確認是證據，不是真值**：必須附理由與 ≥ 1 筆佐證；覆核可以多次，也可以撤回。
7. **分數不是機率**：`rule_score` 只用來排序與分流；`calibrated_probability` 在用獨立校準集校準之前固定是 null（schema 強制）。
8. **原始資料可刪除**：保留結構化值、定位、摘錄與雜湊，使評估可以重現；重新抽取則無法重現（05 §6）。

## v0.3 修訂（2026-10-18，【建議預設】）
1. **取消 dependency_group**，改成根來源模型：`source_origin`、`evidence_derivation`（具型別參照 `ref_type` + `id` + `role`）、`origin_relation`。複製、轉載、裁切、OCR、轉錄、覆核引用都沿用上游根來源；推論的根來源加上 SYSTEM。
2. **關係判定**依序：共享根來源 → SAME；含 SYSTEM → 不獨立；關係紀錄；I2（同一陳述者）→ DEPENDENT；人工 INDEPENDENT；I3（雜湊線索）→ UNKNOWN；I1（使用者本人的原始觀測 vs. 第三方內容，取得紀錄就是正面佐證）→ INDEPENDENT；其他 → UNKNOWN。**UNKNOWN 一律不算獨立**。v0.3.1（使用者決定 D-011）：不同仲介**不**自動代表獨立；沒有正面佐證時維持 UNKNOWN，需要附佐證的 `origin_relation = INDEPENDENT`。
3. `review_id` 只是操作紀錄；內容雜湊只是線索。
4. **連鎖撤回**：任何上游被撤回，就沿著衍生紀錄把依賴證據標為 RETRACTED，並重新評估受影響的評估。
5. **人工確認完整門牌**：依 H1–H6（06 §5.2）判定佐證是否充分；需要直接門牌證據加上刊登連結證據；不必宣稱戶別 mapping 已驗證；逐欄位記錄確認狀態與依據；只填地址、只有照片或只按確認都不充分；撤回後依剩餘佐證重新評估，不固定降級。
6. 人工主張如果只是重新包裝推論，根來源仍含 SYSTEM，不能升級成決定性證據。

## 後果
資料量與實作複雜度增加；換來可解釋、可撤回、可重現的判定。
